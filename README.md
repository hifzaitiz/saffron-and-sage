# Saffron &amp; Sage — Restaurant Website

A fully static, multi-page website built with **HTML5, CSS3 and vanilla JavaScript**
for the Web Technologies course assignment (BS CS F24).

No backend, no database, no frameworks — everything runs in the browser.

## Planned pages

| Page | File | Purpose |
| --- | --- | --- |
| Home | `index.html` | Hero slider, highlights, signature dishes |
| About | `about.html` | Our story, values, team, FAQ |
| Menu | `menu.html` | Filterable menu + build-your-order panel |
| Gallery | `gallery.html` | Photo grid with lightbox |
| Contact | `contact.html` | Validated contact form, hours, location |

## Folder structure

```
Web_Assignment/
├── index.html
├── about.html
├── menu.html
├── gallery.html
├── contact.html
├── css/      → stylesheet
├── js/       → JavaScript files
└── images/   → illustrations and photos
```

## How to run

Open `index.html` in any modern browser. No build step required.
